# BeeWhoopTailsitter CAD

VibeCAD / FreeCAD airframe from Rad CAD.

## Files

- `BeeWhoopTailsitter.FCStd` — main model
- `BeeWhoopTailsitter.stl` — mesh export (viz; skip printing prop discs)
- `build_bee_whoop_tailsitter.py` — rebuild script (`BEE_*` objects)
- `project.vibecad.json` — VibeCAD project metadata

## Geometry lock (v0)

Span 120 mm; mean chord 48 mm; motors Y ±30 mm; prop discs 40 mm; elevons 15 mm chord / 8 mm root gap; AIO tray 32×36×8 mm; AUW ~100 g; T/W target 2.0 (check 0802/1S).
